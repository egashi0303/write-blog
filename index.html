Article Production Platform

案件管理から記事とサムネを量産する運用基盤

案件情報を共有し、記事を生成し、サムネを作り、Drive とスプレッドシートへ保存する。 複数案件を同じ流れで回すための実運用アプリです。

GitHub 運用フロー
公開状態 GitHub Pages / Vercel 対応

静的ページとしてそのまま公開できる構成です。

保存先 案件別フォルダ + スプレッドシート

記事本文はローカル、成果物は Drive と Sheets に集約します。

運用フロー

01

案件の情報を共有する

案件ID、案件名、商品・テーマ、目的、CTA、必須条件、想定読者をまとめます。

02

コンセプトを決める

記事の切り口とサムネの方向性を決め、重複を避けます。

03

記事を自動生成する

案件ごとに1本ずつ、過去記事との重なりを避けながら生成します。

04

Drive と Sheets に保存する

案件名フォルダの中にスプレッドシートとサムネを保存し、リンクを反映します。

このリポジトリでできること

  • 複数案件を同時に回す記事生成
  • 案件別スプレッドシートの管理
  • Canva 優先のサムネ生成とフォールバック
  • Google Drive / Google Sheets への自動保存
