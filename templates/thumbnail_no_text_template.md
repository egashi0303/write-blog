# Thumbnail No-Text Template

## Use Case

記事タイトルや本文から、後で文字を載せる前提のサムネイル背景を生成する。

## Mandatory Rule

This is a text-zero template.

- Use a blank image-first composition
- Do not rely on social-post or headline templates
- Do not allow readable text, captions, labels, ribbons, badges, or title blocks
- If the candidate contains any readable text or text-like block, reject it and regenerate

## Preferred Canva Base Type

- `desktop_wallpaper`

## Prompt Skeleton

```text
Create a photorealistic editorial photo, not an illustration, not a vector graphic, not a 3D render, not a cartoon.
Use a blank, text-zero canvas with no typography, no caption blocks, no title blocks, and no labels.
```
